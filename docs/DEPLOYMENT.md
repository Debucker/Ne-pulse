# Deployment

Two parts: the **backend** (`cmd/nepulse-server`, one Go binary plus a SQLite file on persistent storage) and the **website** (`web/`, Next.js, static pages, on Vercel).

## Backend

The service must stay up. A host that sleeps when idle, like Render's free plan, disconnects every phone, and anything without a persistent disk loses the dataset and every area's learned background rate.

### Option A: VPS (recommended for the research deployment)

2 vCPU / 2 GB RAM handles a few thousand phones (see the load test in `docs/RESEARCH.md`).

```bash
# on your machine
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -o nepulse-server ./cmd/nepulse-server
scp nepulse-server deploy/nepulse.service deploy/Caddyfile user@host:
# on the host
sudo useradd --system --home /var/lib/nepulse nepulse
sudo install -D -m 755 nepulse-server /opt/nepulse/nepulse-server
sudo install -D -m 600 .env.production.example /etc/nepulse/nepulse.env   # then fill in secrets
sudo cp nepulse.service /etc/systemd/system/ && sudo systemctl enable --now nepulse
sudo cp Caddyfile /etc/caddy/Caddyfile && sudo systemctl reload caddy      # TLS for api.ne-pulse.com
```

In `/etc/nepulse/nepulse.env` set `NEPULSE_CLIENT_IP_HEADER=X-Real-IP` (Caddy overwrites it). Firewall everything except 80/443.

### Option B: Render (current provider)

`render.yaml` defines a Docker web service with a 5 GB disk at `/data` on the Starter plan. Secrets are generated by Render. Production currently sits behind **Cloudflare → Render**. In that chain:

- set `NEPULSE_CLIENT_IP_HEADER=CF-Connecting-IP`, and
- verify: `./scripts/verify-production.sh https://api.ne-pulse.com https://ne-pulse.com $ADMIN_TOKEN`. The resolved IP must equal your public IP. If it shows a Cloudflare or Render address, rate limits and network-source diversity are wrong; fix the header setting before inviting anyone.

### Configuration

Every flag of `nepulse-server -h` can be set as `NEPULSE_<FLAG>`. See `.env.production.example`. Required: `NEPULSE_SECRET`, `NEPULSE_ADMIN_TOKEN`, `NEPULSE_ALLOWED_ORIGINS`, `NEPULSE_CLIENT_IP_HEADER`. Optional: Telegram (`NEPULSE_TELEGRAM_TOKEN`, `NEPULSE_TELEGRAM_CHAT`, level `confirmed`), a webhook, catalogue settings, `NEPULSE_EVIDENCE_LOG`.

**Telegram:** create a bot with @BotFather, add it as an administrator of the channel, and set `NEPULSE_TELEGRAM_CHAT=@your_channel`. Messages are sent only at the configured level, once per event, at most 12 per hour, and always carry the "not an official warning" disclaimer.

### Personal alerts (Telegram bot)

1. Create a bot with @BotFather and copy its token.
2. Set `NEPULSE_BOT_TOKEN=<token>` (optional: `NEPULSE_BOT_LEVEL=confirmed`, `NEPULSE_BOT_RADIUS=250`).
3. Restart. The log prints `telegram bot @name: personal alerts ...`; the site's "Get alerts in Telegram" button appears automatically (the server publishes the bot's name in `/api/v1/config`).

The bot long-polls Telegram, so it needs no webhook or open port. Each subscriber gets one personal message per event with the warning time for their 10 km area, computed at the moment of sending (subscribers with the least positive warning time are messaged first). `/test` in the bot sends a clearly labelled drill.

### Research recording (class codes)

- `NEPULSE_RECORD_DIR=/var/lib/nepulse/recordings` turns recording on; `NEPULSE_RECORD_DAYS=365` sets retention.
- `NEPULSE_COHORTS=TASH-9B,TASH-10A` registers class codes at startup (or `POST /api/admin/cohorts {"code":"TASH-9B","note":"..."}` with the admin token).
- Share `https://ne-pulse.com/join?class=TASH-9B`: the code is pre-filled. Only devices with a valid code are recorded continuously.
- Download: `GET /api/admin/recordings?cohort=TASH-9B` lists files; `GET /api/admin/recordings/file?path=...` downloads one (admin token). Or copy the folder with `scp -r`.
- Size: a phone at 60 Hz is about 1.5 MB per hour compressed; 150 phones recording 8 h a night is about 1.8 GB per night. Size the disk for the retention you choose.

### Backups

The whole state is one SQLite file (WAL mode). Back it up with `sqlite3 nepulse.db ".backup backup.db"` (safe while running), for example nightly.

## Website (Vercel)

Project root `web/`. Environment variables (see `web/.env.production.example`):

- `NEXT_PUBLIC_API_URL=https://api.ne-pulse.com` (**required**; build-time)
- optionally a keyed basemap (`NEXT_PUBLIC_TILE_*`). The default Esri tiles need no key. CARTO now requires one.

`next.config.mjs` sets CSP, Permissions-Policy (motion and location), HSTS, and redirects the old `/dashboard` routes. `public/sw.js` removes the old offline-alarm service worker from returning visitors.

## Where to host (as of 30 Sep 2026)

- **ne-pulse.com already runs on Vercel** (the domain is registered elsewhere; DNS points to Vercel). Vercel can keep hosting the website.
- **The backend cannot run on Vercel**: it keeps thousands of WebSocket connections open for hours and writes a database. It needs a small always-on server (Option A, 2 vCPU / 2 GB, roughly $5–12 per month) at `api.ne-pulse.com`.
- **Uzbekistan:** the personal-data law (ZRU-547, amended 2021) requires personal data of citizens to be stored on servers in Uzbekistan. NE-PULSE stores no names, but device records, Telegram chat IDs and class recordings may still count as personal data. The safest choice is a VPS located in Uzbekistan; confirm with the school before recruiting under-18 participants.

## Go-live checklist

1. Deploy the backend with secrets; `curl https://api.ne-pulse.com/api/health`.
2. Deploy the site with `NEXT_PUBLIC_API_URL`.
3. Run `scripts/verify-production.sh` with the admin token: all PASS, and the resolved IP matches.
4. Join from two real phones (iPhone Safari, Android Chrome). Each should reach **Listening** within about a minute.
5. Leave Telegram alerts unset until a few days of background data have been collected (new areas carry a pessimistic prior anyway).
6. For a class: get the information sheet (`docs/consent/`) approved by the school, register the class code, then share `https://ne-pulse.com/join?class=CODE`.
7. Then share `https://ne-pulse.com/join`.
